# IX-Ray Artwork

This repository contains all official artwork and styling elements for the **IX-Ray Platform**. This includes logos, color palettes, wallpapers, social media covers, and splash screens. The goal is to maintain a consistent and professional visual identity across all platforms and media.

## 1. Brand Identity

### 1.1. Primary Typography

The primary typeface for all graphical elements containing text is **Blender Pro**.

* **Usage:** All splash screens, logos with text, and promotional graphics.

## 2. Splash Screens

Splash screens are the first visual point of contact. They must be clean, professional, and immediately recognizable as part of the IX-Ray Platform.

### 2.1. Core Specifications

* **Required Text:** All splash screens must feature the text **"IX-Ray Platform"**.
* **Font:** **Blender Pro**.
* **Layout:** The composition should be balanced, with the logo and text being the central focal point.

### 2.2. Platform-Specific Requirements

Splash screens must be delivered in the exact dimensions and file formats specified below.

| Platform | Dimensions (Width x Height) |
| :------- | :-------------------------- |
| **YouTube** | 2048 x 1152 px |
| **VK**      | 1920 x 768 px |
| **ModDB**   | 950 x 150 px |

## 3. File Structure & Naming Convention

All artwork files should be organized logically. Please use the following naming convention:

```
[platform]_[asset-type]_[variant].[extension]
```

**Examples:**

* `youtube_splash_platform.png`
* `vk_splash_platform.png`
* `moddb_header_platform.jpg`
* `logo_primary.svg`
* `logo_icon_monochrome.png`

## 4. Delivery & Quality Assurance

* **Resolution:** All raster images (PNG, JPG) must be delivered in the exact specified dimensions.
* **Quality:** No pixelation or compression artifacts.
* **Transparency:** Where applicable (e.g., logos), provide files with transparent backgrounds (PNG, SVG).
* **Vector Assets:** All logos and simple graphical elements must also be provided in SVG format for scalability.
